# Atividade conceitual
## Parte 1

1. Qual alternativa melhor define JPA?
c) Especificação

2. Em qual estado uma entidade é monitorada pelo contexto de persistência?
b) Managed

3. Qual alternativa melhor define Hibernate?
a) Framework ORM

4. Qual alternativa melhor define ORM?
b) Técnica de mapeamento objeto-relacional

5. Sobre EntityManager, qual alternativa é verdadeira?
b) É utilizado para gerenciar o ciclo de vida das entidades

6. Sobre EntityManagerFactory, qual alternativa é verdadeira?
b) É utilizado para criar instâncias de EntityManager e só deve haver uma instância por aplicação

## Parte 2

1. Qual alternativa melhor define o Hibernate?
a) Framework ORM

2. Em qual arquivo é configurada a Persistence Unit em um projeto Java com Maven?
b) persistence.xml

3. Qual anotação JPA é utilizada para indicar que uma classe é uma entidade no contexto da JPA?
b) @Entity

4. Qual anotação JPA é utilizada para mapear um relacionamento N:1 (Many-to-One) entre entidades?
b) @ManyToOne

5. Qual anotação JPA é utilizada para mapear um relacionamento 1:N (One-to-Many) entre entidades?
a) @OneToMany

6. Qual anotação JPA é utilizada para mapear um relacionamento N:N (Many-to-Many) entre entidades?
d) @ManyToMany

7. Qual anotação JPA é utilizada para definir o nome da tabela no banco de dados que será mapeada pela entidade?
a) @Table

8. Qual anotação JPA é utilizada para definir o mapeamento de um atributo da classe para uma coluna da tabela no banco de dados?
d) @Column

9. Qual anotação JPA é utilizada para indicar que um atributo da classe é a chave primária da tabela no banco de dados?
c) @Id

10. Em relacionamentos bidirecionais, qual é o lado que possui a chave estrangeira (FK) no relacionamento N:1 (Many-to-One)?
b) O lado "N" (Many)
